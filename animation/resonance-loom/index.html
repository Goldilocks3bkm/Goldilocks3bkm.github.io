音声・プライバシー・対応環境について ＋

音は外へ送信しません

音声の読込・解析・録音はブラウザー内だけで処理します。解析サービス、広告、外部フォント、アクセス解析は使っていません。設定や音声を永続保存しないため、再読込・タブを閉じると消えます。必要な録音は先にWAVを保存してください。

サイトを開く際の配信サーバーへの通常の通信は発生します。ファイルの内容やマイク音を送信する仕組みはありません。

WAVを中心に、ブラウザーで再生

PCM WAV を基本に、MP3・FLAC はブラウザーのデコーダーが対応している場合に再生できます。拡張子だけでは対応を保証できません。圧縮WAV等は非対応の場合があります。この試作はファイル150 MiBまで・展開後の音声150 MiBまでです。ファイルを全体デコードするため、長尺・高サンプルレート音源はメモリーを多く使います。圧縮形式の展開量はデコード後に判定するので、一時的なメモリー確保までは防げません。

マイクはHTTPSまたはlocalhost上で、許可操作後のみ起動。入力をスピーカーへ返しません。録音は最大5分、モノラル・16-bit PCM WAVで保存できます。タブを非表示にすると録音を終了します。

動きと操作の配慮

端末の「視差効果を減らす」等の設定では、はじめから静止します。「動きを再開」で任意に有効にできます。結び目と仕立てはキーボード操作にも対応。画面の動きを止めても、音声の再生・録音は止まりません。

最新のChrome / Edge / Firefox / Safari向けの試作です。実ブラウザーでの描画・音声再生・マイク録音・保存、実端末での操作は未検証です。構文・静的構造・ロジックの自動テストとは区別してください。対応や動作は環境ごとに異なります。BPM・楽器・感情の認識は行いません。

つくりと出自

Canvas 2D、Web Audio、AudioWorklet、Pointer Events を使った独自実装。外部ライブラリ・画像・音源の依存はありません。お試し音源もブラウザー内で生成するオリジナルです。第三者素材のライセンスは不要です。公開ライセンスは未選択です。このページの公開によって、MIT等の再配布ライセンスを付与するものではありません。

APIの参照：Web Audio 仕様 / Media Capture 仕様。記事や作例コードの転載はしていません。

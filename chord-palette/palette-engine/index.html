「音を有効にする」で演奏を始められます。

音例を聴き比べる

白い帯の交点

白い帯で枠1、枠2、両枠の交点OFF／ONの順。12秒からは緑の下塗りで両枠の交点OFF／ON。各3秒、C3で音量を合わせています。

塗膜波形

均一、太い縞、細い縞、練った縞の順。同じ場所をC3で押さえ、正弦波から塗膜波形へ切り替えた二音を聴けます。

境界の響き

OFF、打音、粒、溶ける、残響、色と重なりで変化。各2.5秒、同じ絵をC3で演奏。

筆目の刻み

等間隔、詰まる縞、広がる縞、縞に沿う。同じ鍵盤と速度で比較。

同じ白へ

白に着いた後だけを比較。黄から、青から。次に通過色を切った同じ二音。

光で描く

境目 → 重色 → 細縞 → 4枠。それぞれ光をオフ、オンの順。

塗り方

均一な混色 → 太い横縞 → 細い横縞

読み方

ワープ → 重ね読み → 溶かすワープ

筆とにじみ

前半は3つの混ぜ方、後半は筆目とにじみ
